# MyJavaLessons

This project consists of basic Java examples prepared for Java programming practice. Each file demonstrates a different topic or problem type. The files in this project are small and straightforward applications that can be used to learn fundamental Java concepts.

## Project contents

- `soru1.java`: Finds numbers divisible by 3 from 1 up to a given number, then prints their total and count.
- `soru2.java`: Takes a number from the user, then calculates the sum of values greater than 5 from randomly generated numbers.
- `soru3.java`: Reads five grades, calculates the average, finds the highest grade, and prints whether the student passed or failed based on the average.
- `soru4.java`: Generates a specified number of random numbers, calculates the sum of even numbers, and tries to find the smallest odd number if any are produced.
- `soru5.java`: Takes a base and exponent, calculates the result, and prints whether the result is greater than, equal to, or less than 100.
- `soru6.java`: Uses cinema ticket pricing and age discounts to calculate the total cost for the user. The process ends when 0 is entered.

## Compile and run

You can compile and run each Java file separately with the following steps:

```bash
javac soru1.java
java soru1
```

Similarly for the other files:

```bash
javac soru2.java
java soru2
```

```bash
javac soru3.java
java soru3
```

```bash
javac soru4.java
java soru4
```

```bash
javac soru5.java
java soru5
```

```bash
javac soru6.java
java soru6
```

## .class files

The project also contains `soru1.class`, `soru2.class`, `soru3.class`, `soru4.class`, `soru5.class`, and `soru6.class`. These are compiled versions of the Java source files, meaning they are executable bytecode generated by the `javac` command.

## Purpose

This project is designed to help beginners learn the core building blocks of Java:

- reading user input (`Scanner`)
- loops (`for`, `while`)
- conditional statements (`if`, `else if`, `else`)
- mathematical operations
- random number generation (`Random`)
- total, average, and comparison operations

## Result

This repository provides small but educational examples for people who are just starting to learn Java. Each file solves a different problem and helps reinforce the basic logic of programming.
